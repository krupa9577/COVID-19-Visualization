# COVID-19-Visualization
Data visualization project using Python, Matplotlib, and Seaborn to analyze global COVID-19 data.
## 📌 Project Overview

This project focuses on analyzing and visualizing global COVID-19 data using **Python, Matplotlib, and Seaborn**.

The project demonstrates how data visualization can be used to understand COVID-19 cases, deaths, vaccinations, distributions, and relationships between different variables.

## 🎯 Objectives

- Learn data visualization using Matplotlib and Seaborn
- Create different types of charts
- Analyze COVID-19 trends across countries
- Understand distributions and correlations
- Apply proper chart formatting and design principles
- Create a final 2×2 COVID-19 dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Anaconda

## 📊 Visualizations

The project includes:

1. **Line Chart** – COVID-19 cases over time for India, USA, and Brazil
2. **Bar Chart** – Top 10 countries by COVID-19 deaths
3. **Histogram** – Distribution of COVID-19 cases
4. **Correlation Heatmap** – Relationship between cases, deaths, and vaccinations
5. **2×2 Dashboard** – Global COVID-19 analysis
